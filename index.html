Machine Learning Pipeline

How The System Works

The project follows a structured machine learning workflow from behavioral data collection to real-time classification.

01

Data Collection

Behavioral screening attributes and participant demographic information are collected as model input features.

02

Preprocessing

Categorical variables are transformed through fitted label encoders to create model-compatible numerical representations.

03

Random Forest

The processed attributes are passed to the trained Random Forest classifier consisting of multiple decision trees.

04

AI Prediction

The system generates a binary ASD screening classification and instantly presents the result through the interactive dashboard.
